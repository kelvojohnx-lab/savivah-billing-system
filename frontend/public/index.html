Hotspot Configuration Guide

How it works

When a voucher is generated (manually or after M-Pesa payment), Savivah pushes the voucher code as a hotspot user to your MikroTik router via the RouterOS REST API. The customer connects to your WiFi, opens a browser, and enters their voucher code on the hotspot login page.

Step 1
Customer pays via M-Pesa
STK Push → PIN → Confirmed
Step 2
Voucher auto-generated
Pushed to MikroTik hotspot
Step 3
Code sent to customer
Login to WiFi with code

Network Architecture
📱 Customer phone → WiFi → MikroTik hotspot redirect → Login page
💳 Customer dials M-Pesa → Safaricom → Callback to this server
🖥️ This server → MikroTik REST API → Adds hotspot user with time limit
✅ Customer enters voucher code → Internet access granted for purchased duration
